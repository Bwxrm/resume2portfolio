# Resume2Portfolio

**Transform your resume into your own personal website.**

Resume2Portfolio is a full-stack web application designed to help students, developers, and professionals turn traditional resumes into personalized portfolio websites without needing to write code.

## Project Overview

Users will be able to upload their resumes, automatically extract important information, customize their portfolio design, and generate a professional website they can share with employers and recruiters.

## Planned Features

- Resume upload (PDF and DOCX)
- Automatic resume information extraction
- AI-assisted professional summaries
- Customizable portfolio templates
- Personal profile and skills sections
- Projects and work experience sections
- Live website preview
- Portfolio publishing and shareable links

## Tech Stack

- React / Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PDF.js
- OpenAI API (planned)
- Vercel

## Development Status

🚧 Currently in development.

This project is being built as a personal Software Engineering project to explore full-stack development, document processing, API integration, and AI-powered applications.

Create an accessible platform that makes professional online portfolios easier to build, customize, and share.
